# Kunal Chinche — GIS Portfolio

This is a responsive, single-page portfolio website built from the information in the supplied CV.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository (for example, `kunal-gis-portfolio`).
3. Upload `index.html` and `README.md`.
4. In repository Settings, open Pages.
5. Choose deployment from the `main` branch and the root folder, then save.
6. GitHub will provide the public website URL after deployment.
